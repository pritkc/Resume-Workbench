Main Finding

The primary tailoring output cap is very conservative, but the largest immediate waste is the cover-letter/outreach prompt. It sends both a compact candidate profile and a large full tailored resume JSON block.

Recommended Changes

Area Recommended change Why it matters
Cover/outreach input Replace full tailored resume JSON with bounded evidence snippets. Biggest input reduction, less PII exposure, closer to intended compact payload design.
Cover/outreach output Lower cap from 2600/3200 retry to about 1200/1800. The captured output was only about 324 estimated tokens.
Tailoring output Use adaptive caps: normally about 9000 for full, lower for lite, keep 15000 for huge contracts. Current 15000 cap inflates timeout planning and is much higher than observed output.
Timeouts Add per-call timeout overrides and keep primary calls inside the 240s preview limit. Current JSON timeout math can exceed the route-level timeout.
JD extraction Keep 4096 for now. One mixed run is not enough to safely lower it.
