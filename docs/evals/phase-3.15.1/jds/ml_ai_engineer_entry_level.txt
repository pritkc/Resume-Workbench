Entry Level ML / AI Engineer
Company: ClaimForge AI
Location: San Mateo, CA

ClaimForge AI helps operations teams review documents, classify risk, and route work with human-in-the-loop AI systems. We are looking for an early-career ML / AI engineer who can build practical LLM and machine learning features in production software.

Responsibilities:
- Build Python services that call LLM APIs for document extraction, classification, and structured outputs.
- Create evaluation datasets, error analysis workflows, and lightweight quality checks for model outputs.
- Integrate AI features into backend APIs and review queues used by analysts.
- Work with PostgreSQL, FastAPI, React, Docker, and CI/CD pipelines.
- Communicate limitations clearly and keep humans in the loop for sensitive decisions.

Qualifications:
- New grad or 0-2 years of software, data, research, internship, or project experience.
- Strong Python fundamentals and practical experience with APIs.
- Exposure to scikit-learn, MLflow, prompt evaluation, or OpenAI / similar LLM APIs.
- Ability to ship grounded engineering work rather than research-only prototypes.
- Healthcare, fintech, insurance, or trust-and-safety domain exposure is a plus.
