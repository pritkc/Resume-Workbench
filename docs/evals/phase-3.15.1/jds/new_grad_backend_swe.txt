# New Graduate — Backend / API (SWE)

Acme is hiring New Graduate Software Engineers for our Core API team in San Francisco (hybrid).

You will build and maintain REST and event-driven services in Python and Go, work with PostgreSQL and Redis, and contribute to Kubernetes-deployed microservices. We use gRPC between services and Kafka for domain events.

Requirements: BS or MS in Computer Science or related field; graduation date within 12 months. Strong fundamentals in data structures, algorithms, and at least one systems language. Coursework or internships involving distributed systems or databases preferred.

Nice to have: Experience with AWS (ECS, RDS), Terraform, or observability (OpenTelemetry, Grafana).

We sponsor visas for exceptional candidates. Expect close mentorship and code review from senior engineers; you will not own production on-call alone in your first month.
