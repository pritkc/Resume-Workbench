Entry Level Data Engineer
Company: Northstar Health Analytics
Location: Remote, US

Northstar Health Analytics builds data products for care quality and claims operations teams. We are hiring an entry-level data engineer to help build reliable pipelines, validation checks, and analytics datasets used by analysts and product teams.

Responsibilities:
- Build and maintain Python and SQL data pipelines for healthcare claims and operational datasets.
- Write dbt models, tests, and documentation for analytics-ready tables.
- Use Airflow or similar orchestration tools to schedule recurring data workflows.
- Partner with analysts to investigate data quality issues and improve reporting reliability.
- Work with cloud data platforms such as BigQuery, Snowflake, Redshift, or PostgreSQL.

Qualifications:
- New grad or early-career engineer with internship, research, project, or 0-2 years of professional experience.
- Strong SQL and Python fundamentals.
- Familiarity with dbt, Airflow, data validation, ETL/ELT, and dashboard consumers.
- Healthcare, fintech, or operations analytics exposure is a plus.
- Ability to explain tradeoffs and debug issues without overstating ownership.
